I build geospatial AI that measures environmental exposure (urban heat, air quality, land change) and then tests whether the result holds up: when the map unit changes, against ground measurements, and against what people actually experience.

- 60+ peer-reviewed journal articles (21 as first author), 6,980 citations, h-index 45 on [Google Scholar](https://scholar.google.com/citations?user=vkBgMkIAAAAJ) (October 2026)
- Field program across all 254 Texas counties: 1,400 stratified sites, 22,400 seasonal records with 79 variables each, satellite-to-ground temperature error cut from 20.7 °F to about ±3 °F
- Teaching Environmental GIS and Land Use/Land Cover Change Practicum in UT Austin's GeoAI Undergraduate Certificate

**[GeoXVIEW](https://github.com/AbdullaKafy/GeoXVIEW)**: dissertation framework for scale-adaptive environmental exposure in Texas. Five layers from satellite to street level, field-calibrated bias correction, MAUP diagnostics across five map units, Python package and a [live dashboard](https://abdullakafy.github.io/GeoXVIEW/).

**[landsat-climate-ml](https://github.com/AbdullaKafy/landsat-climate-ml)**: one tested Python toolkit for land cover change, LST, UHI, UTFVI, CA-ANN prediction, carbon stock and drought from Landsat. Eleven published studies (about 1,180 citations) each get a page with the published tables as data, a key figure and runnable sample code.

**[green-roof-cooling-lidar](https://github.com/AbdullaKafy/green-roof-cooling-lidar)**: lidar urban form and neural networks to test green roof cooling, with a worked example on open USGS 3DEP lidar for downtown Austin.

**[publications-code](https://github.com/AbdullaKafy/publications-code)**: every journal article with DOI, citations and a link to its code where one exists.
